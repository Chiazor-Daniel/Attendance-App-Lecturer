# Attendance App — Lecturer

A **React Native** (bare CLI) attendance app for **lecturers**.

Start a class/session and track student attendance live:

- **ClassSession** — create and start a session
- **SessionRules** — define rules before opening attendance
- **AttendanceInSession / AttendanceInProgress** — live attendance status screens
- **SessionSuccess** — wrap-up confirmation

## Run

```bash
npm install
# iOS: npx pod-install && npm run ios   ·   Android: npm run android
```
